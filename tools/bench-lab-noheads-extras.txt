# Benchmark lab WITHOUT the jarred heads: the same scene as bench-lab.txt with every headblock and jarhead line left
# out (turrets, arrays, mounts and sockets stand empty, no placed jarred heads), because in the released mod drawing
# any jarred head crashes the client (Pose stack not empty). This is the scene the baseline numbers were taken on;
# compare later waves on this file, and on bench-lab.txt once heads draw.
# Benchmark lab: 42 machines, 4 mecha, a jar holding a pig with Telekinesis (scene from the performance review, 7.2).
# Three scenarios, each settled and then timed in 30-second windows by "bench start/stop" (frame times on the render
# thread, server tick times on the server thread, packets per second, entity count, the debug screen's fps string),
# with "/tick query" read back by cmdout after each window.
#   A: the lab, the player a jar holding the pig by Telekinesis, looking at the lab (3 windows), then the same with the
#      camera turned away (render cost against tick cost), a window watched by the stand-in player (packets by type),
#      a window under /debug (time per ticker, written to the game folder's debug/), and a 5-second frames capture.
#   B: the jar piloting the fitted Colossus (3 windows).
#   C: the player linked (head in a jar on the ground, body standing), no Telekinesis (3 windows).
# Run: bash tools/smoke.sh tools/bench-lab.txt   (SMOKE_MODS / SMOKE_PROFILE / SMOKE_SHADER for the other configurations)
@world flat
# Peaceful, as in bench-lab-noheads.txt (no slimes; no husk targets)
