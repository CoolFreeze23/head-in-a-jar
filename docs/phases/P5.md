## Deviations from the design

- **No Gene Port slots in the Gantry.** Serums go into a Chimera by hand, the same as hosts. That keeps one injection path and the Gantry screen unchanged; the genes still survive disassembly on the frame item.
- **Host actives:** hosts carry passive genes. R/G on a host still fire the host's own abilities, so gene actives on hosts would need a third key.
- **The Chimera** reuses the Hopper's bones and gets its own skin; no separate model yet (P7 art pass).
- **Numeric effects:** players and hosts get 70% of a gene's numeric effect, while a Chimera gets 100%. Movement genes are synced to every client watching the body, because the client that steers it applies them.
- **Ideas only** from Genetics Resequenced (LGPL): the sample → centrifuge → sequencer → splice chain. No code or assets are reused.
